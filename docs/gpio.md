# Работа с GPIO

## Что такое GPIO

**GPIO** (General Purpose Input/Output) — это контакты на плате, через которые можно подключать разные устройства: светодиоды, кнопки, датчики, сервоприводы. Как гнёзда для периферии — в каждый можно «воткнуть» нужное устройство и управлять им из программы.

На Обрике GPIO-пины расположены на 40-пиновом разъёме JST-SH. Управление выполняется через библиотеку **sverk_interfaces** — единый API дрона, который скрывает под собой работу с libgpiod.

> **Внимание** GPIO 14/15 заняты UART (связь с полётным контроллером), GPIO 20 — SPI1 MOSI (светодиодная лента). Не используйте эти пины для других целей.

## Проверка доступных пинов (диагностика)

Эти команды — только для проверки и отладки. Управлять пинами в коде — через `drone.gpio.*`.

```bash
# Покажет список GPIO-чипов (обычно gpiochip0, gpiochip1...)
gpiodetect

# Покажет информацию о каждом пине чипа
gpioinfo gpiochip0
```

> **Примечание** Эти команды выполняются **внутри контейнера** `sverk_ros2`. Устройства видны благодаря пробросу `/dev` через docker compose.

> **Примечание** GPIO-контроллер одинаков на всех платах — `/dev/gpiochip0`. Различия по другим интерфейсам (UART, SPI, камера) → [Бортовые компьютеры](knowledge_base/boards-overview.md).

## Управление из Python — вывод (OUTPUT)

**Что мы делаем:** включаем и выключаем цифровой выход на пине GPIO17 через API Обрика.

```python
import sverk_interfaces

# Создаём объект дрона — он инициализирует все подсистемы
drone = sverk_interfaces.init(Nodename="gpio_example")

# Включаем пин 17 (HIGH = 3.3 В на выходе)
drone.gpio.pin_on(17)

# Выключаем пин 17 (LOW = 0 В)
drone.gpio.pin_off(17)

# Освобождаем пин после использования — важно, иначе другие процессы не смогут его занять
drone.gpio.pin_release(17)

# Завершаем работу с дроном
drone.close()
```

---

## Управление из Python — чтение (INPUT)

**Что мы делаем:** читаем состояние кнопки или датчика на GPIO24.

```python
import sverk_interfaces

drone = sverk_interfaces.init(Nodename="gpio_example")

# Читаем состояние пина: вернёт 0 (LOW) или 1 (HIGH)
value = drone.gpio.pin_read(24)
print(f"GPIO24 = {value}")

# Освобождаем пин после использования
drone.gpio.pin_release(24)

drone.close()
```

## Пример: мигание светодиодом

**Что мы делаем:** включаем светодиод на GPIO17 на 1 секунду, потом выключаем — в цикле.

```python
import time
import sverk_interfaces

drone = sverk_interfaces.init(Nodename="gpio_example")

try:
    for i in range(5):
        drone.gpio.pin_on(17)   # включить
        time.sleep(0.5)          # ждём полсекунды
        drone.gpio.pin_off(17)  # выключить
        time.sleep(0.5)
finally:
    # Всегда освобождаем ресурсы, даже если случилась ошибка
    drone.gpio.pin_release(17)
    drone.close()
```

## Пример: опрос кнопки в цикле

**Что мы делаем:** читаем кнопку каждые 100 мс и печатаем изменения состояния.

```python
import time
import sverk_interfaces

drone = sverk_interfaces.init(Nodename="gpio_example")

# Запоминаем предыдущее состояние, чтобы реагировать только на изменения
prev = drone.gpio.pin_read(24)

try:
    while True:
        cur = drone.gpio.pin_read(24)
        if cur != prev:
            # Состояние изменилось — реагируем
            print(f"Кнопка {'нажата' if cur == 1 else 'отпущена'}")
            prev = cur
        time.sleep(0.1)
finally:
    drone.gpio.pin_release(24)
    drone.close()
```

## Электрические ограничения

> **Внимание** GPIO работает на 3.3 В — подача 5 В напрямую выведет плату из строя.

Перед подключением любого устройства соблюдайте эти правила:

| Правило | Пояснение |
|---------|-----------|
| GPIO работает на **3.3 В** | Нельзя подавать 5 В напрямую — сгорит |
| Нельзя подключать силовую нагрузку напрямую | Для мотора, реле, электромагнита нужен **транзисторный ключ** или **драйвер** |
| При внешнем питании — общая земля | GND бортового компьютера и GND внешнего источника должны быть соединены |
| Для катушек — защитный диод | Индуктивная нагрузка (мотор, реле) при выключении даёт обратный выброс напряжения |
