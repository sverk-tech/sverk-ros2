# Симулятор для ручного пилотирования

Перед первым полётом на реальном Обрике потренируйтесь в симуляторе — управление стиками там работает так же, а ошибка ничего не повредит.

Основы управления стиками перед практикой: [Ручное пилотирование](manual-flight.md)

---

## Веб-симулятор

Откройте [Песочницу](https://edu.sverk.tech/sandbox) на платформе «Сверх».

Зарегистрируйтесь на сайте, выберите модель дрона. Для управления стиками подключите аппаратуру к компьютеру через USB — она определится как игровой контроллер автоматически.

**Доступные режимы:**

- **STABILIZED** — дрон сам держит горизонт, высоту держите вы газом
- **ACRO** — полностью ручное управление без стабилизации, для опытных пилотов

Начинайте всегда с STABILIZED.

---

## Что отрабатывать

1. Взлёт и посадка — плавный набор и сброс газа.
2. Удержание позиции — стики в центр, дрон должен висеть на месте.
3. Движение вперёд/назад, влево/вправо — правый стик.
4. Разворот — левый стик влево/вправо (Yaw).

Тренируйте каждый пункт отдельно, потом соединяйте вместе. Удержание позиции с одновременным разворотом — это уже серьёзный навык.

---

## Переход к автономному управлению

Когда уверенно летаете руками — переходите к программированию. Автономный полёт начинается с двух строк кода:

```python
import sverk_interfaces
drone = sverk_interfaces.init(Nodename="my_first_auto")
drone.control.navigate(x=0.0, y=0.0, z=1.5, frame_id="body", auto_arm=True)
```

Подробнее про автономный полёт в симуляторе: [Симулятор (автономный)](knowledge_base/simulation.md)
