# Работа с камерой

Камера Обрика снимает то, что находится под дроном, и постоянно отправляет кадры в систему. Дрон использует эти кадры, чтобы находить ArUco-маркеры на полу и понимать, где он находится.

Технически: камера подключена по интерфейсу MIPI CSI к бортовому компьютеру и публикует изображения в ROS 2 топик `/camera_1/image_raw`.

> **Примечание** Физически устройство подключено к пинам платы (хоста). Контейнер `sverk_ros2` видит эти устройства через `/dev` благодаря пробросу в docker compose. Работайте через `drone.gpio.*` / `drone.image.*` — выходить из контейнера не нужно.

> **Примечание** Драйвер CSI-камеры зависит от платы (RPi CM5 — `cam0`, Orange Pi Zero 3W — `vin_v4l2`, Orange Pi 5 Pro — `rkisp1`), но ROS 2 топик `/camera_1/image_raw` одинаков на всех — код от платы не зависит. Полная таблица интерфейсов по платам → [Бортовые компьютеры](knowledge_base/boards-overview.md).

---

## Как проверить, что камера работает

Откройте терминал на Обрике и запустите:

```bash
ros2 topic hz /camera_1/image_raw
```

> **Примечание** Эти команды выполняются **внутри контейнера** `sverk_ros2`. Устройства видны благодаря пробросу `/dev` через docker compose.

Если камера работает, увидите частоту публикации кадров — например, `30.0 Hz`. Если ничего не выводится или команда зависает, проверьте, что шлейф камеры плотно вставлен в разъём на плате.

Можно также посмотреть одно сообщение:

```bash
ros2 topic echo /camera_1/image_raw --once
```

---

## Просмотр изображения

Самый простой способ: откройте веб-интерфейс по IP-адресу Обрика в браузере и перейдите в раздел просмотра изображения.

Полный веб-интерфейс с визуализацией ROS-топиков доступен по адресу `http://<IP_ДРОНА>:5173`.
