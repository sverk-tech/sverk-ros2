# Работа с QGroundControl (QGC)

QGroundControl (QGC) — это программа для настройки и мониторинга полётного контроллера Обрика. Через неё можно посмотреть телеметрию, откалибровать датчики, обновить прошивку и задать параметры полёта.

Когда Обрик включён, QGC показывает всё, что происходит с полётным контроллером: ориентацию в пространстве, напряжение батареи, режим полёта и сигналы с пульта управления.

---

## Как подключиться

Обрик поддерживает два способа подключения к QGC:

- [Подключение по Wi-Fi](../qgc-wifi.md) — основной способ. Обрик создаёт точку доступа, вы подключаетесь к ней с компьютера.
- [Подключение по проводу (USB)](qgc-usb.md) — резервный способ, если Wi-Fi не работает или недоступен.
