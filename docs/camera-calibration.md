# Калибровка камеры

Калибровка измеряет искажения объектива и параметры матрицы камеры, чтобы программа могла их компенсировать. Управление калибровкой доступно из Python через `drone.image.calibration`, качество результата оценивается по RMS error.

---

## Физика: почему камеры искажают изображение

Дисторсия — это геометрическое искажение, которое вносит линза: прямые линии у краёв кадра выгибаются наружу или внутрь. Калибровка измеряет это искажение, чтобы программа могла его компенсировать.

Для человека такое искажение почти незаметно. Но для алгоритма, который вычисляет расстояние до объекта или позицию маркера, каждый пиксель важен. Если пиксель по краю кадра сдвинут на 5 пикселей от «правильного» места, алгоритм ошибётся в расчёте позиции.

Калибровка камеры решает это так:
1. Показываем камере объект с известной геометрией (шахматную доску с клетками строго определённого размера).
2. Измеряем, насколько реальное изображение клеток отличается от «идеального».
3. Сохраняем эти отклонения в файл. Теперь программа умеет их исправлять.

В результате получается два набора чисел:
- **Матрица K** (camera matrix) — описывает фокусное расстояние и центр изображения.
- **Коэффициенты дисторсии** — описывают, как именно линза искажает картинку.

## Подготовка

**1. Камера работает.** Убедитесь, что кадры идут:

```bash
ros2 topic list | grep image
```

Откройте веб-интерфейс и проверьте, что изображение приходит. Если нет — сначала разберись с драйвером камеры, потом возвращайся сюда.

**2. Запустите ноду калибровки.** В отличие от ядра, нода `camera_calibration` **не входит в автозапуск** ([главный launch-файл](main-launch.md)) — подними её сам, указав топик камеры:

```bash
ros2 launch camera_calibration calibration.launch.py image_topic:=/camera_1/image_raw
```

Результаты по умолчанию сохраняются в `~/camera_calibrations`. Нода поднимает сервисы `/calibration/*` — дальше всё делается из Python через `drone.image.calibration`, вручную `ros2 service call` вызывать не нужно.

## Калибровка через `drone.image.calibration`

Весь цикл — это вызовы методов `drone.image.calibration`. Разберём по шагам, а в конце — цельный программа.

### 1. Задать параметры доски

Передайте параметры именно своей доски. Примеры:

```python
import sverk_interfaces

drone = sverk_interfaces.init(Nodename="calibrator")
cal = drone.image.calibration   # None, если нода camera_calibration не запущена

# ChArUco (шахматная доска с ArUco-маркерами; удобна при плохом освещении)
cal.set_config(board_type="charuco", camera_model="pinhole",
               board_width=11, board_height=8,
               square_size=0.022, marker_size=0.016,
               aruco_dict="DICT_4X4_50", min_frames=10)

# Обычная шахматная доска:
# cal.set_config(board_type="chessboard", board_width=10, board_height=7, square_size=0.022)

# Круговая сетка:
# cal.set_config(board_type="circles", board_width=11, board_height=8, square_size=0.022)
```

Параметры `set_config`:
- `board_type` — тип доски: `chessboard`, `charuco`, `circles`
- `camera_model` — `pinhole` (обычная) или `fisheye` (рыбий глаз)
- `board_width`, `board_height` — количество внутренних узлов по ширине и высоте
- `square_size` — размер клетки (или расстояние между центрами), в метрах
- `marker_size` — размер ArUco-маркера для `charuco`, в метрах
- `aruco_dict` — словарь маркеров для `charuco`
- `min_frames` — минимум кадров для расчёта
- `save_captures` — сохранять ли кадры на диск (по умолчанию `True`)

### 2. Начать сессию и собрать кадры

```python
cal.start_session()                  # чистая сессия (cal.reset_session() — сбросить и удалить кадры)

cal.set_auto_capture(True, period_sec=1.0)   # автозахват раз в секунду
# медленно води доской перед камерой ~15-20 секунд
cal.set_auto_capture(False)                   # выключить автозахват
```

Нода публикует превью с отмеченной доской в топик `/calibration/processed_image` — откройте его в веб-интерфейсе, чтобы видеть, что доска распознаётся. Нужно набрать 10-15 кадров, где доска:
- в разных частях кадра (не только по центру),
- наклонена под разными углами,
- видна полностью, без обрезки,
- не размыта и не засвечена,
- на разных расстояниях от камеры.

Можно захватывать и вручную, по одному кадру:

```python
cal.capture()
```

### 3. Проверить и почистить кадры

```python
print(cal.get_state())        # словарь: сколько кадров, статус и т.д.
print(cal.list_captures())    # список накопленных кадров
cal.remove_capture(0)         # удалить плохой кадр по индексу (с 0)
```

### 4. Рассчитать и сохранить

```python
cal.calibrate()   # рассчитать параметры камеры (может занять время)
cal.save()        # сохранить latest_calibration.yaml в output_dir
drone.close()
```

### Всё вместе

```python
import time
import sverk_interfaces

drone = sverk_interfaces.init(Nodename="calibrator")
cal = drone.image.calibration

if cal is None:
    print("Нода camera_calibration не запущена — подними её через ros2 launch")
else:
    cal.set_config(board_type="charuco", board_width=11, board_height=8,
                   square_size=0.022, marker_size=0.016, aruco_dict="DICT_4X4_50")
    cal.start_session()

    cal.set_auto_capture(True, period_sec=1.0)
    time.sleep(20.0)                      # води доской перед камерой
    cal.set_auto_capture(False)

    print("Состояние:", cal.get_state())
    cal.calibrate()
    cal.save()

drone.close()
```

## Как понять, что калибровка хорошая

После калибровки система выводит **RMS error** (среднеквадратичная ошибка репроекции). Это среднее расстояние в пикселях между тем, где должен быть угол клетки по модели, и где он реально оказался на кадре.

- **RMS < 1.0 пикселя** — хорошо, можно использовать.
- **RMS 1.0-1.5 пикселя** — приемлемо, но стоит добавить кадров с разных ракурсов.
- **RMS > 1.5 пикселя** — плохо. Удалите размытые или однообразные кадры (`cal.remove_capture(...)`) и повторите `cal.calibrate()`.

Файл `latest_calibration.yaml` после `cal.save()` лежит в `output_dir` (по умолчанию `~/camera_calibrations`). Его можно передать драйверу камеры или узлам обработки изображения.

---

## Советы

- Не используйте только фронтальные кадры — чем разнообразнее углы, тем лучше.
- Не двигайте доску слишком быстро: кадры смазываются.
- Не набирайте десятки почти одинаковых кадров с одного места.
- Если `drone.image.calibration` равен `None` или методы падают с ошибкой «service is not available» — нода `camera_calibration` ещё не запущена или не успела подняться.
- Если кадр не захватывается, чаще всего доска плохо видна или её параметры не совпадают с `set_config`.
